# admission-specialty-predictor

# Модель подбора специальности для поступления

## Основные характеристики

| Параметр | Значение |
|----------|----------|
| **Язык программирования** | C++ |
| **Среда разработки** | Qt Creator, CLion | 
| **Тип проекта** | Мини-приложение на Qt |

## Состав проекта

1. **Иерархия классов поступающих**
2. **SQL-база данных** университетов и специальностей
3. **Приложение** (графический интерфейс + логика)

## Задачи разработки

- [ ] **Парсинг данных**, их распаковка и перенос в БД

- [ ] **Методы и функции-обработчики** слотов, сигналов и событий

## Логика работы программы

### Входные данные

Модель запрашивает у абитуриента: **ФИО**, **средний балл аттестата**, **тип учебного заведения**, **экзаменационные предметы** и **проходные баллы** по каждому предмету (для поступающих в ВУЗ), **сфера интересов** (предметная область), **форма обучения** (бюджет / платное).

### Обработка данных

1. Модель, используя **правила**, выполняет **SQL-запрос** на выборку.
2. Определяется **вероятность поступления** (по умолчанию — на бюджет) для каждой специальности.

### Вывод результатов

- Приложение выводит **список подходящих специальностей**, где вероятность поступления **> 50%**.
- **Рекомендуемые** специальности (вероятность **> 75–80%**) выделяются.

### Обработка пустого результата

Если список пуст: предлагается выбрать **платную форму обучения** или рассмотреть **ССУЗ** (если до этого был выбран ВУЗ).

### Завершение работы

Абитуриент может **завершить работу с приложением в любой момент времени**.
